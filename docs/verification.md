# Verification

## Scope

route-race: model source and focused tests, static asset/syntax checks, browser interaction, remote workflow and public site are separate evidence levels. Existing unrelated services remain outside this change.

## Evidence

### 도전·추적·미션 확장 QA 범위 / 2026-10-09 / LOCAL ONLY

검사 대상: 변경 전 저장소 입력 16개 파일(architecture, README, decisions, verification, .gitattributes, .gitignore, package.json, workflow, HTML/CSS/model/UI/app, 기존 모델 테스트, check/serve)을 전체 읽었습니다. 지정된 route-race 문서·코드·테스트는 VERIFIED입니다. 다른 서비스는 NOT_INSPECTED / 작업 범위 밖입니다. 이번 파일 변경은 route-race에만 있습니다.

기본 QA는 위 흐름을 기준으로 기능과 화면을 따로 확인합니다. 실패 코드·단절 지도·한도 초과를 정상 흐름 외 탐색 대상으로 삼습니다. 외부 링크·원격 배포는 열거나 실행하지 않습니다.

#### 이번 확장 실행 증거

- LOCAL_MODEL: `npm test` 13/13 통과. 원래 4개 회귀 테스트 + 새 독립 오라클/추적/입력/미션 테스트 9개. 다섯 가족×120시드=600개, 독립 생성180개, 각 가족 uint32 최대 시드, 단절/S=E/최대30×20/전부험지를 검사했습니다. BFS는 독립 단위 비용 오라클, Dijkstra/A*는 독립 가중치 Bellman-Ford와 대조했습니다. Weighted w=1/1.5/2/3/4의 경로 유효성과 w=1 동등성, w>1 실제 비용 손실 반례도 확인했습니다.
- LOCAL_STATIC: `npm run check` 통과. 공개 자산5개 구문/로컬 참조/메타데이터/CSP/엄격 UTF-8/BOM 없음/CRLF/모델의 UI·저장소 의존 없음 검사. 변경11개 텍스트 파일도 UTF-8 without BOM/CRLF 확인, `git diff --check` 통과.
- BROWSER_LOCAL_IAB: Codex 별도 로컬 IAB 탭 `http://127.0.0.1:54800/`에서 실제 클릭/선택/키보드/마우스 드래그로 위 흐름을 검사했습니다. 다섯 가족의 코드 재현 후 비교 텍스트가 동일했고, 새 시도12회의 코드가 서로 달랐습니다. 예측 일치/불일치/잠금/무예측/초기화, w=4 반례 및 w=1 동등성, 설계3칸 비용차이10 달성, 9칸 한도 초과, 지도 단절, S=E 비용0, undo/restart/sample/blank와 다섯 그리기 도구를 확인했습니다. 재생은 3→8단계 진행 후 정지, 한 단계와 슬라이더 Home/End를 확인했습니다.
- TRACE_LOCAL_IAB: 단계1에서 꺼낸 출발 g=0/h=17, 후보2칸과 다음 후보 표를 확인했습니다. 완료 시 남은 후보가 이후 탐색하지 않는다는 설명, 네 전략의 경로/비용/확장/최대 후보와 실제 갱신 수를 확인했습니다. 모델 테스트는 후보 순서·우선값·g 개선의 합법성을 별도로 재구성하여 대조합니다.
- RESPONSIVE_LOCAL_IAB: 1280×720, 390×844, 320×780. 초기 지도/도구, 힌트/피드백, 완료 경로, 후보 표를 스크린샷으로 확인했습니다. 페이지 가로 넘침 없음; 320px 완료 상태 후보 표 너비231px/부모231px로 맞습니다. 긴 문구 줄바꿈과 결과 읽기를 확인했습니다. 세로 스크롤을 사용하는 페이지입니다.
- WEBMCP_LOCAL_IAB: 실제 네 전략 요약 읽기와 missing paint mode 거절 확인. UI 조작 검증과 도구 호출 검증을 구분합니다.
- CONSOLE_LOCAL_IAB: 이 로컬 탭의 캡처된 warning/error 로그0개. 모든 브라우저나 서버 상태의 증거는 아닙니다.
- SCREENSHOT_LOCAL: `tmp/weighted-comparison.jpg`는 RR1-lure-0/w=4의 실제 경로/비용23 대61/확장43 대20 화면입니다. tmp는 무시되며 배포 자산이 아닙니다.
- NOT_RUN: 주 화면의 MAIN_VISIBLE QA(이 실행의 브라우저 도구가 visible=true를 허용하지 않음), 실제 터치 장치/터치 취소, OS reduced-motion 환경, 페이지 숨김/종료 이벤트의 브라우저 실행 검증, 독립 스크린리더, 다른 브라우저. 공유 포인터 처리와 생명주기 구현은 읽었지만 실행 증거로 승격하지 않았습니다. 위 재실행 흐름으로 메인 브라우저에서 보완할 수 있습니다.
- REMOTE/LIVE: NOT_RUN. 커밋·푸시·배포·원격 CI·공개 페이지 확인·새 에이전트 생성 없음. 이 기록은 새 코드를 공개 페이지가 실행한다는 증거가 아닙니다.

#### 주 브라우저에서 다시 실행하기 좋은 흐름

1. `npm run dev -- 0`의 로컬 URL을 여세요. `RR1-trap-2026`을 재현하고 "그렇다"→결과 보기. BFS 17회/비용65, Dijkstra 23회/비용23과 예측 일치를 확인합니다.
2. `RR1-lure-0`, w=4, "아니다"→결과 보기. A* 비용23/43칸, Weighted 비용61/20칸과 예측 불일치를 확인합니다. w=1로 바꾸면 예측·결과가 지워지고 두 전략의 비용/확장 수가 같아집니다.
3. 미션을 "8칸 비용 차이 설계"로 바꾸고 험지 도구 선택. 편집기에 Tab 진입, 오른쪽 3번→Space→오른쪽→Enter→오른쪽→Space. 결과 보기에서 편집3/8, 비용 차이10, 달성 확인. undo는 편집2/8과 이전 결과 폐기를 보여줍니다.
4. 미로/관문/황야를 각각 선택해 코드와 결과를 기록한 뒤 같은 코드로 재현하세요. 한 단계와 슬라이더 Home/End로 실제 후보 표·갱신·완료 경로를 비교합니다.
5. `RR1-maze-4294967296` 거절 시 기존 지도 유지. 기본 지도 S의 오른쪽·아래·왼쪽·위 칸을 벽으로 막으면 모든 전략 "경로 없음", 예측 채점 불가. 다시 시작하면 원본 복원.
6. 작은 화면에서 힌트를 열고 결과/후보 표/가중치 선택/지도 도구를 확인하세요. 터치 드래그와 취소, reduced-motion 시작 정지, 숨긴 페이지의 재생 정지는 주 브라우저에서 추가 확인할 수 있습니다.

이 확장은 커밋·푸시·배포·원격 쓰기를 하지 않았습니다. 원격 CI/공개 페이지/MAIN_VISIBLE QA는 로컬 모델 또는 별도 탭 검사로 대체 증명하지 않습니다.
