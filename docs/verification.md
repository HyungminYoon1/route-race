1. 이 저장소에서 `npm run dev -- 0` 실행 후 출력된 로컬 URL을 여세요. 초기 화면에서 첫 방문 자체가 완료 기록을 만들지 않는지 확인합니다. 기존 브라우저 기록이 있으면 "기기 완료 기록 → 완료 기록 지우기"를 사용합니다.
2. "기본 지도"를 누르고 "그릴 험지 비용"을 **9**로 바꾼 뒤 "험지 · 비용 9" 선택. 편집기에 Tab 또는 클릭으로 포커스를 놓고 출발 S에서 **오른쪽 → Space**를 누르면 화면 6행 3열에 비용9가 그려집니다. w를 **4**로 선택하고 "결과 보기"를 누릅니다.
3. "지도 코드 내보내기 · 가져오기"를 열고 "코드 만들기". 코드와 비용9 칸, w=4, 실제 경로/비용/확장 수를 캡처합니다. "현재 지도 복사"를 누르면 현재 상태의 새 코드를 복사합니다. 권한 거절 시 선택된 텍스트를 Ctrl+C로 복사합니다. 코드 만들기만으로 클립보드에 쓰지 않습니다.
4. 복사한 코드를 보관한 뒤 "빈 지도"(설계 비용5)로 교체합니다. 코드 칸에 원래 코드를 붙여넣고 "가져오기". 비용9/S/E/원본 배열 및 w=4 복원, "결과 보기" 후 이전 수치/경로 동일성을 캡처합니다. **가져오기 자체나 그 결과 보기는 완료 1/1을 만들면 안 됩니다.** "되돌리기" 한 번은 직전 빈 지도/설정으로 돌아갑니다.
5. 전체 S/E 보존을 확인하려면 다시 코드를 가져온 후 "출발 S" 도구로 평지 칸을 선택하고 "도착 E"도 다른 칸으로 옮깁니다. 새로운 코드를 생성·복사하고 위 교체/붙여넣기/가져오기를 반복하여 두 엔드포인트와 모든 칸이 그대로인지 확인합니다. "다시 시작"은 가져온 지도와 비용/w를 복원합니다.
6. 코드의 `"version":1`을 `"version":2`로 바꾸거나 `"extra":1`을 추가하여 가져오기. 오류와 기존 지도 유지 확인. 코드 8192자 초과·타일 수 불일치·벽 S/E·비용0/100도 거절해야 합니다. 단절 지도와 S=E는 유효하며 각각 경로 없음/비용0을 표시해야 합니다.
7. **힌트를 닫고** "빈 지도"를 눌러 새 독립 설계를 시작합니다. "험지 · 비용 5" 선택 후 편집기에 Tab으로 진입하여 **오른쪽×3 → Space → 오른쪽 → Space → 오른쪽 → Space**. "결과 보기"에서 **편집3/8, S/E 유지, BFS 비용29, Dijkstra 비용19, 차이10, 목표 달성**을 캡처합니다. "기기 완료 기록"을 열면 **독립 설계 완료1/1**. 새로고침 후1/1 유지 및 갤러리 요약의 날짜가 불필요하게 바뀌지 않는지 확인합니다.
